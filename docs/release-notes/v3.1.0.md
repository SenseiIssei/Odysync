Odysync 3.1 makes looking after a computer one click — or none at all.

## Highlights

- **Smart Care.** Odysync now opens on a single care score. Every point it takes off is listed with the reason, so the number is never a scare tactic. *Fix everything* installs the safe updates and clears the junk files in one go, while a ring shows what it is doing.
- **Automatic care.** Flip one switch and Odysync installs safe updates and clears junk files on its own, daily or weekly. It uses the same safety checks as a manual run.
- **Drivers always wait for you.** Drivers, firmware and system upgrades are never part of one-click or automatic care, and neither are developer packages such as pip or npm, which your projects may depend on. They are listed for you to start.
- **Disk and battery health** on Windows, macOS and Linux, read from what the hardware reports about itself: failing disks, wear, temperature and how much charge the battery still holds.
- **PowerShell 7 and Shotcut** join the apps updated straight from their publishers. Both installers were inspected and their signatures pinned before being added.
- **A new look**: animated, calmer and simpler, in light and dark.

## Command line

```sh
odysync care --dry-run      # what automatic care would do
odysync care                # do it
odysync schedule --frequency daily --care
odysync health              # disk and battery health
```

## Install

Pick the package for your system below; each file has a `.sha256` next to it. The releases are not code-signed yet — see the README for what SmartScreen and Gatekeeper will say and how to proceed.
