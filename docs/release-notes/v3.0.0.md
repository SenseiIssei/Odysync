Odysync 3.0 updates software without winget, redesigns the app, and brings most of what paid "PC optimizer" suites offer — minus the parts that only look busy — to Windows, macOS and Linux.

## Highlights

- **Direct from the publisher.** Installed programs are updated straight from GitHub releases and vendor feeds. Every installer must carry a valid signature from the publisher Odysync expects, match the published SHA-256, and is locked against tampering until it has run. winget is now an optional extra source.
- **NVIDIA drivers from NVIDIA.** The right WHQL driver for your GPU, from NVIDIA's own service, refused unless signed by NVIDIA Corporation.
- **Mac apps through their own update feeds.** Apps with a Sparkle feed are updated only with a valid Ed25519 signature from the key in the app you already have, the same Apple Team ID, and Gatekeeper's approval.
- **Cleanup on every platform**, grouped by risk: safe caches by default, your choice for things with a cost, a second confirmation for anything permanent. New: GPU shader caches (often tens of gigabytes on gaming PCs) and the recently-opened-files list.
- **Runtimes, devices, driver backups.** Visual C++, DirectX and .NET from Microsoft's own installers; Device Manager error codes explained in plain words; driver-store backup and restore in the app.
- **Startup manager and system info on Windows, macOS and Linux**, reversible and without root.
- **A calmer interface** with light and dark themes.

## Fixes worth knowing about

- GPU detection found no adapter on non-English Windows (pnputil translates its labels).
- Signature checks failed when Odysync was started from PowerShell 7.
- Schedules created in the app opened the window instead of running an update.
- Optional sources could not be switched on from the app.

## Install

Pick the package for your system below; each file has a `.sha256` next to it. The releases are not code-signed yet — see the README for what SmartScreen and Gatekeeper will say and how to proceed.
