A security and speed update for Odysync 3.1.

## Security

- The TLS certificate checks Odysync relies on for every download could accept distrusted intermediate certificates (RUSTSEC-2026-0382, RUSTSEC-2026-0383). Both libraries are updated.

## Faster

- **Scans are about three times faster.** Windows Update, Defender definitions and feature upgrades now share one search instead of queueing three identical ones. On the test machine a full scan went from 34 s to 12 s, and from minutes to under one on a cold start.
- **The app opens with what it found last time** and refreshes in the background, instead of an empty page.

## Fixed

- PowerShell modules from the PowerShell Gallery are actually checked for updates now (the old scan never found one), in 7 s instead of 30 s. An update installs exactly the version that was checked.

## Install

Pick the package for your system below; each file has a `.sha256` next to it. The releases are not code-signed yet — see the README for what SmartScreen and Gatekeeper will say and how to proceed.
